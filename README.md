# NÉRAVIE — Maison de Parfum

Luxury perfume storefront front-end, with original imagery, product details, browsing, wishlist, cart, and checkout preview. This site is a presentation front-end; real payments and order submission are not enabled.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, source **main**, folder **/(root)**, and click **Save**. The site will be served at `https://isaacrobinson087-max.github.io/neravie-client-preview/` once GitHub Pages completes publishing.

The entire website is static, with the interface and styles in `index.html` and original fragrance imagery in `assets/`.
